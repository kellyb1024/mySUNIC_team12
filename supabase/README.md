# Supabase 연동

프로토타입의 데이터를 HTML 안 배열에서 실제 DB로 옮기는 절차입니다.
**연결 전에도 프로토타입은 그대로 돕니다** — `SUPA` 값이 비어 있으면 로컬 배열로 동작합니다.

## 1. 프로젝트 만들기

1. https://supabase.com 에서 프로젝트 생성 (무료 티어로 충분)
2. 지역은 **Northeast Asia (Seoul)** 을 고르면 응답이 빠릅니다
3. 만들 때 정한 DB 비밀번호는 따로 보관하세요 (이 연동에는 안 씁니다)

## 2. 표 만들고 데이터 넣기

대시보드 좌측 **SQL Editor** 에서 순서대로 실행합니다.

| 파일 | 하는 일 |
|---|---|
| `01_schema.sql` | `campaigns` · `capa` 표 생성, 인덱스·제약·실시간 구독 설정 |
| `02_seed.sql` | 캠페인 204건 적재. 다시 실행해도 안전합니다 |
| `03_capa_guard.sql` | **동시 신청 캐파 보장.** 저장 직전에 하루 캐파를 다시 세고, 같은 날 쓰기를 한 줄로 세웁니다 |

> `03` 은 **화면에서 막을 수 없는 것을 막습니다.** 두 사람이 같은 날 마지막 자리를
> 동시에 신청하면, 둘 다 화면 검사를 통과합니다 — 검사한 시점에는 정말 자리가 있었으니까요.
> 저장소가 순서를 정해 줘야 뒤에 온 쪽이 막힙니다. 안 걸면 캐파를 넘긴 채로 저장됩니다.

## 3. 앱에 주소와 키 넣기

저장소 안 **`config.js`** 두 줄만 채우면 됩니다.
대시보드 **Project Settings → API** 에서 복사하세요.

```js
window.SUPA_CONFIG = {
  url: 'https://xxxxxxxx.supabase.co',
  key: 'eyJhbGciOi…',      // anon (public) 키
};
```

### .env 는 왜 안 쓰나

빌드 과정이 없는 정적 HTML 이라 브라우저가 `.env` 를 읽을 방법이 없습니다.
값은 결국 서빙되는 파일 안에 들어가야 하고, GitHub Pages 는 저장소에 있는
파일을 그대로 내려주므로 `config.js` 는 커밋해야 배포본이 동작합니다.

`.gitignore` 에 넣으면 내 컴퓨터에서는 되지만 **배포된 페이지는 연결되지 않습니다.**

> **`service_role` 키는 절대 넣지 마세요.** 그 키는 모든 권한을 가지며
> 정적 페이지에 넣는 순간 누구나 볼 수 있습니다.
> `anon` 키는 공개되는 것이 정상이고, 접근 범위는 아래 RLS 정책이 정합니다.

## 4. 확인

- 페이지를 열고 콘솔에 `[DB] 서버 연결 · 실시간 구독 시작` 이 찍히는지
- 두 창을 나란히 열고 한쪽에서 신청 → 다른 쪽에 몇 초 안에 뜨는지
- 주소 뒤에 `?db=local` 을 붙이면 서버를 켜 둔 채로 로컬 데이터로 볼 수 있습니다
  (UT·스냅샷 비교용)

## 지금 권한 설정에 대해 — 읽어 주세요

**저장소가 공개(public)라 `config.js` 의 anon 키도 공개됩니다.**
anon 키는 원래 브라우저에 노출되는 것이라 그 자체가 사고는 아니지만,
지금은 로그인이 없어 **키를 본 사람이 데이터를 넣고 고칠 수 있습니다.**

그래서 `01_schema.sql` 에서 **지우기(delete)만은 막아 뒀습니다.**
최악의 경우에도 통째로 사라지지는 않고, `02_seed.sql` 을 다시 돌리면
원래 204건으로 돌아옵니다.

  읽기   허용
  넣기   허용   ← 마케터 신청
  고치기 허용   ← 담당자 확정·취소
  지우기 없음

데모·내부 검토용으로는 이 정도면 됩니다. 실제 운영으로 넘길 때는
로그인을 붙이고 정책을 역할별로 좁혀야 합니다.

  마케터 — 전체 읽기, 본인 건만 쓰기
  담당자 — 전체 읽기·쓰기

키가 새어 곤란해지면 대시보드에서 **키를 새로 발급(rotate)** 하고
`config.js` 만 바꿔 다시 배포하면 됩니다.

## 데이터를 다시 만들려면

`02_seed.sql` 은 `no` 가 같으면 덮어씁니다. 완전히 비우고 다시 넣으려면
SQL Editor 에서 `truncate campaigns;` 를 먼저 실행하세요.
